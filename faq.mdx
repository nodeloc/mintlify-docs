<AccordionGroup>
  <Accordion title="为什么我不能发私信 / 发链接 / 上传头像？">
    这些功能需要提升信任等级才能解锁：
    - 主动发私信、发链接、传头像：白银会员 (TL1)
    - 聊天频道：黄金会员 (TL2)
    - 创建节点：钻石会员 (TL3)
    
    多浏览、多互动即可快速升级，详见[能量与信任等级](/level)。
  </Accordion>

  <Accordion title="能量有什么用？怎么获得？">
    能量可用于打赏、发红包、买抽奖奖券、购买付费内容、转账等。获取方式包括每日签到、发帖、回复、获赞等，详见[能量系统](/energy/points)。
  </Accordion>

  <Accordion title="签到按钮在哪里？为什么点不了？">
    登录后页面右上角有"每日签到"按钮，每天可点一次。已签到时会显示"您今天已经签到过了"，详见[每日签到](/energy/checkin)。
  </Accordion>

  <Accordion title="如何参与抽奖？">
    先回复抽奖主题，然后点击抽奖卡片上的"参与抽奖"购买奖券（1 能量/张）。买的越多中奖率越高，但每人最多中一次，详见[抽奖](/features/lottery)。
  </Accordion>

  <Accordion title="转账手续费是多少？">
    手续费按你的信任等级收取，从 0.5%（王者）到 10%（青铜）不等，由转出方额外支付。完整费率和限额见[能量系统](/energy/points#手续费与限额)。
  </Accordion>

  <Accordion title="发的帖子能修改或删除吗？">
    发布后限定时间内可以点击楼层右下角 ✏️ 编辑，也可以删除。主题作者还可以把重要回复[置顶](/getting-started/posting#管理自己的内容)。
  </Accordion>

  <Accordion title="如何绑定 Telegram 通知？">
    在 Telegram 联系 @nler_bot 获取 Chat ID，然后到 偏好设置 → 个人资料 → Telegram 通知 中填写，详见[Telegram 通知](/common/telegram)。
  </Accordion>

  <Accordion title="收不到邮件通知怎么办？">
    - 检查垃圾邮件文件夹。
    - 在 偏好设置 → 电子邮件 中确认邮箱地址和通知频率设置。
    - 可以改用 [Telegram 通知](/common/telegram) 作为替代。
  </Accordion>

  <Accordion title="账号被封禁 / 禁言了怎么办？">
    封禁和禁言通常由违规行为导致。页面会显示原因和期限。如有异议，可通过邮件联系管理员申诉：james@nodeloc.com。
  </Accordion>

  <Accordion title="如何在论坛投放广告或成为认证商家？">
    访问[推广中心](https://www.nodeloc.com/promotion)自助购买，支持支付宝和 USDT，即买即开。详见[广告投放](/promotion/ads)与[认证商家](/promotion/merchants)。
  </Accordion>

  <Accordion title="我想把 NodeLoc 账号接入自己的网站登录，怎么做？">
    NodeLoc 提供 OAuth 2.0 / OIDC 登录对接，黄金会员 (TL2) 以上可创建应用，详见[开发者文档](/api-reference/introduction)。
  </Accordion>

  <Accordion title="遇到问题在哪里反馈？">
    - 功能建议与问题反馈：[建议反馈节点](https://www.nodeloc.com/c/internet/suggestion/54)
    - 文档纠错：给[知识库仓库](https://github.com/nodeloc/mintlify-docs)提 PR，见[共建知识库](/create)
    - 邮件：james@nodeloc.com
  </Accordion>
</AccordionGroup>
