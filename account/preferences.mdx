偏好设置用于定制你的论坛体验。访问方式：点击右上角头像 → 个人资料 → 偏好设置，或直接访问 [/my/preferences](https://www.nodeloc.com/my/preferences)。

## 常用设置页

| 设置页 | 内容 |
| --- | --- |
| 帐户 | 用户名、邮箱、**能量余额**、能量历史入口 |
| 安全性 | 修改密码、Passkey、登录活动记录 |
| 个人资料 | 头像、简介、签名、用户卡片背景、[Telegram 通知](/common/telegram) |
| 电子邮件 | 邮箱地址与邮件通知频率 |
| 通知 | 各类事件的站内通知开关（回复、点赞、关注等） |
| 跟踪 | 默认跟踪/静音的节点和标签 |
| 用户 | 忽略与静音指定用户 |
| 界面 | 主题、字号、语言等界面偏好 |
| 导航菜单 | 自定义侧边栏显示的节点和标签 |
| 聊天 | 聊天功能的通知与声音设置 |

## 界面个性化

- **颜色模式**：侧边栏底部的切换按钮可在浅色/深色模式间切换。
- **自定义版块**：侧边栏底部"添加自定义版块"可以把常用节点固定在首页侧边栏。
- **语言**：界面语言支持中文和英文，在 偏好设置 → 界面 中切换。

## 通知管理建议

- 默认情况下，有人回复你、@你或点赞时都会收到通知。
- 邮件通知频率可在"电子邮件"页调整，不常上线的话建议开启"摘要邮件"。
- 想摆脱论坛提醒时，可使用 跟踪 页中的"静音"功能，而不是直接忽略所有通知。
