---
title: "Telegram 通知"
description: "绑定 Telegram，即时接收论坛通知"
---

通过 Telegram 关联，您可以在 Nodeloc 论坛接收即时通知，方便及时了解社区动态。

## 绑定步骤

<Steps>
  <Step title="获取 Chat ID">
    打开 Telegram，联系机器人 [@nler_bot](https://t.me/nler_bot)，机器人会自动返回一个您的**唯一 Chat ID**。
  </Step>
  <Step title="填写 Chat ID">
    登录 Nodeloc 论坛，进入 [偏好设置 → 个人资料](https://www.nodeloc.com/my/preferences/profile)，找到"Telegram 通知"，将机器人返回的 ID 填入并保存。
  </Step>
  <Step title="开始接收通知">
    保存成功后，论坛的私信、回复、点赞等通知会同步推送到您的 Telegram。
  </Step>
</Steps>

  <img src="/images/screenshots/telegram-setting.png" alt="偏好设置中的 Telegram 通知字段" />
</Frame>

## 注意事项

- 留空该字段即可**禁用** Telegram 通知。
- 如果未收到通知，请检查 ID 是否填写正确，或重新从机器人获取后再次保存。
- 确保您已开启 Telegram 的消息通知权限，且没有屏蔽 @nler_bot。

<Tip>
  Telegram 通知是论坛站内通知的补充，重要的账号安全通知仍会以邮件形式发送。
</Tip>
