title: "隐藏内容"
description: "回复可见、登录可见、付费可见三种内容标签的用法"
---

发帖时可以把部分内容隐藏起来，要求读者满足特定条件（回复、登录或付费）后才能查看。常用于资源分享、福利发放等场景。但是，近期论坛没有开放使用此功能，所以暂时不要使用。

## 三种标签

| 标签 | 语法 | 效果 |
| --- | --- | --- |
| 回复可见 | `[reply]内容[/reply]` | 读者在本主题回复后可见 |
| 登录可见 | `[login]内容[/login]` | 仅登录用户可见，游客显示"请登录后查看内容" |
| 付费可见 | `[pay amount=100]内容[/pay]` | 读者支付指定能量后可见 |

也可以直接在编辑器工具栏点击对应按钮（回复可见 / 登录可见 / 付费可见）插入标签，付费可见会弹出金额设置窗口。

### 使用示例

```markdown
感谢大家支持，下载地址在这里：

[reply]
https://example.com/download
[/reply]
```

## 付费可见详解

### 定价规则

- 金额单位是能量，默认 100，最高 10,000。
- `amount` 写在标签里：`[pay amount=50]...[/pay]`。
- 主题作者本人始终可见自己的付费内容。

### 购买流程

1. 读者看到"此内容仅对支付了 N 能量的用户可见"的提示。
2. 点击"支付 N 能量查看"，确认后立即扣款并显示内容。
3. 页面会显示已有多少人购买了该内容。

### 手续费

购买付费内容时，**买家需额外支付手续费**，费率随信任等级递减：

| 信任等级 | 手续费率 |
| --- | --- |
| 青铜会员 (TL0) | 10% |
| 白银会员 (TL1) | 8% |
| 黄金会员 (TL2) | 5% |
| 钻石会员 (TL3) | 3% |
| 王者会员 (TL4) | 0% |

例如黄金会员购买 100 能量的内容，实际扣除 105 能量，作者收到 100 能量。

<Warning>
  付费购买**不可退款**，支付前会有确认提示，请确认需要再购买。能量不足时会提示"您的能量不足，无法查看此内容"。
</Warning>

## 使用建议

- **回复可见**适合引流互动，但请勿用于无意义内容，过度使用会被视为灌水。
- **付费可见**适合真正有价值的资源、教程、邀请资格等。
- 隐藏内容不要包含违规信息，管理人员可以查看所有隐藏内容。
