Preferences let you customize your forum experience. Access them via your avatar (top right) → Profile → Preferences, or go directly to [/my/preferences](https://www.nodeloc.com/my/preferences).

## Common settings pages

| Page | Contents |
| --- | --- |
| Account | Username, email, **Energy balance**, Energy history entry |
| Security | Change password, passkeys, login activity |
| Profile | Avatar, bio, signature, user card background, [Telegram notifications](/en/common/telegram) |
| Emails | Email address and email notification frequency |
| Notifications | On-site notification toggles for various events (replies, likes, follows, etc.) |
| Tracking | Nodes and tags tracked/muted by default |
| Users | Ignore and mute specific users |
| Interface | Theme, font size, language, and other interface preferences |
| Navigation menu | Customize the nodes and tags shown in the sidebar |
| Chat | Notification and sound settings for chat |

## Interface personalization

- **Color mode**: the toggle at the bottom of the sidebar switches between light and dark mode.
- **Custom sections**: "Add custom section" at the bottom of the sidebar pins your frequently used nodes to the homepage sidebar.
- **Language**: the interface supports Chinese and English; switch in Preferences → Interface.

## Notification management tips

- By default, you're notified when someone replies to you, @mentions you, or likes your post.
- Email notification frequency can be adjusted on the "Emails" page; if you don't log in often, consider enabling the "summary email".
- When you want a break from forum alerts, use the "mute" feature on the Tracking page instead of ignoring all notifications.
