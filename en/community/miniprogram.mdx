description: "Mini games and tools that run inside posts: browse the directory, check permissions, and play instantly"
---

Mini apps are interactive applications that run inside NodeLoc topics — they can be mini games, small tools, or bot-assisted moderation tools. They're developed by community members, run in a server-side sandbox, can only use approved permissions, and **cannot access your account**.

## Browsing the Mini App Directory

The "Mini Apps" section of the sidebar lists your apps. Click "Browse more" (or visit [/apps](https://www.nodeloc.com/apps) directly) to see all published mini apps. Each card shows the author, description, install count, and placement type.

## Viewing Details and Permissions

Click a card to open its detail page, where you can see the version, install count, interface type, placement type, and the **full permission list** — so you know exactly what it can do before opening it.

  <img src="/images/screenshots/en/miniprogram-detail.png" alt="Mini app detail page showing the permission list" />
</Frame>

## Using Mini Apps in Topics

Mini apps run inside topics. Click "Open" on the detail page to jump to the topic where it lives and start playing right away:

<Frame>
  <img src="/images/screenshots/en/miniprogram-topic.png" alt="Snake mini app running in a topic" />
</Frame>

- Game scores are verified server-side before entering the leaderboard — the numbers shown on the page don't count, so the rankings are authentic and trustworthy.
- There's a normal discussion area right below the mini app, so you can reply and chat after playing.

## Two Interface Types

| Type | Description | Examples |
| --- | --- | --- |
| Native components | Rendered with the site's own components, matching the site's style | NodeLoc Carpool Assistant |
| Self-drawn UI | The mini app draws its own interface, suited for games | Snake (贪吃蛇), 2048, Minesweeper |

## Adding a Mini App to Your Own Topic

Mini apps whose placement type is "can be added to any topic" can be embedded in your own topics: paste the topic link on the detail page and click "Add to Topic".

<Frame>
  <img src="/images/screenshots/en/miniprogram-add-to-topic.png" alt="Adding a mini app to your own topic" />
</Frame>

<Tip>
  Want to build your own mini app? Mini apps are currently in beta, and development access is granted by user group — contact an admin to get it enabled. Once you have access, see the [mini app development docs](/en/miniprogram/introduction).
</Tip>
