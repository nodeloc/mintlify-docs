## 注册账号

<Steps>
  <Step title="打开注册页面">
    访问 [nodeloc.com](https://www.nodeloc.com)，点击右上角"注册"按钮。
  </Step>
  <Step title="填写信息">
    输入邮箱、用户名和密码。用户名注册后可以在偏好设置中修改一次。
  </Step>
  <Step title="验证邮箱">
    注册后会收到验证邮件，点击邮件中的链接完成验证。未验证邮箱的账号部分功能受限。
  </Step>
</Steps>

<Tip>
  请使用真实可用的邮箱。忘记密码时需要邮箱找回，重要通知也会发送到邮箱。
</Tip>

## 第三方账号登录

除了邮箱密码，NodeLoc 还支持以下登录方式：

| 登录方式 | 说明 |
| --- | --- |
| Google | 使用 Google 账号一键登录 |
| GitHub | 使用 GitHub 账号登录 |
| X (Twitter) | 使用 X 账号登录 |
| Telegram | 使用 Telegram 账号登录 |
| Passkey | 使用设备指纹/面容等通行密钥登录 |

首次使用第三方登录时会自动创建关联账号。建议登录后在 偏好设置 → 电子邮件 中绑定邮箱，避免第三方账号异常时无法登录。

## 找回密码

1. 在登录页点击"忘记密码"。
2. 输入注册邮箱，系统会发送重置链接。
3. 点击邮件中的链接设置新密码。

## 账号安全建议

- **使用强密码**：包含大小写字母、数字和符号，不要与其他网站重复。
- **绑定 Passkey**：在 偏好设置 → 安全性 中添加通行密钥，登录更快更安全。
- **定期检查登录记录**：偏好设置 → 安全性 中可以查看最近的活动会话。
- **警惕钓鱼**：NodeLoc 官方域名是 `nodeloc.com`，不要在其他网站输入论坛密码。

## 完善个人资料

登录后访问 [偏好设置 → 个人资料](https://www.nodeloc.com/my/preferences/profile)，可以设置：

- 头像与用户卡片背景（白银会员 TL1 以上）
- 个人简介、签名
- 网站、位置等公开信息
- [Telegram 通知](/common/telegram) 绑定
